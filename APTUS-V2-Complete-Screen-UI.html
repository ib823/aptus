28 BPMN Process Flow Visualization — Enhancement Proposal

What SAP Signavio Shows

In SAP Signavio Process Navigator, each scope item has process diagrams showing the BPMN 2.0 notation — start events, tasks, gateways (exclusive/parallel), sub-processes, message events, timer events, and end events arranged in swimlanes by role. This is the standard way SAP presents its Best Practices catalog to consultants and clients.

What ABEAM Currently Shows (Phase 20)

ABEAM generates sequential flow diagrams from BPD test script data. The ProcessMapCanvas shows swimlanes with activity clusters. Each node is color-coded by classification status (FIT/CONFIGURE/GAP). Nodes are clickable and support risk overlays. This is functional but lacks the BPMN visual vocabulary that SAP users expect.

Recommendation: Approach A (bpmn-js) is the best balance. It renders standard BPMN notation that consultants recognize from Signavio, while allowing ABEAM to overlay its own classification colors (FIT/CONFIGURE/GAP) on each task node. The BPMN XML can be generated from the existing BPD process step data — mapping SAP process flows to BPMN pools, activities to tasks, and decision points to gateways. This creates a direct visual bridge between what clients see in SAP's tools and what they see in ABEAM.
