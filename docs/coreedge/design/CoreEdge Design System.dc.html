Additions

Proposed tokens

Four additions. Each exists because a screen in this round needs it and A2 has no equivalent.

1 · Dark values for --decision-*
A2 leaves the catalogue classification colours at their light values in dark, where all four fall to 2.5–3.2 : 1. Same hues, lifted.
Standard#5EC9BC · 8.51
Configure#8FB4E8 · 7.95
Custom#E3A46A · 7.89
Open#A3A09A · 6.49
2 · --severity-1…4
The "Needs you" stripe ranks four kinds of work in one queue. It reuses existing semantic ink rather than new hues, and deliberately avoids the CTA red so that red still means "irreversible action"; the stripe is decorative, and the row's words carry the meaning.
--severity-1 · broken now · #991B1B / #F2A097
--severity-2 · expiring · #B45309 / #F2C069
--severity-3 · waiting on you · #1E40AF / #9CC6EA
--severity-4 · ready to collect · #166534 / #7FD29A
3 · --rail-hover · --rail-active
The rail's hover and current-place fills were untokenised inline alphas. Naming them keeps the rail from drifting: they are white over the navy ground, so one pair works for both themes.
Hoverrgba(255,255,255,0.08)
Current placergba(255,255,255,0.12)
4 · --focus-ring-navy
Already written into A2 under decision 10: light #002B5C, dark #8FB4E8. It exists because A2's shipping --focus-ring was the CTA red, which put an irreversible-action colour on every focused element. Destructive controls keep a red ring, so the ring still matches the commit.
Gate colours, status pairs, radii, shadows and motion are A2 as shipped, and all spacing on this page is snapped to the --space-* scale. Control heights (22 · 24 · 26 · 36 px) are not on the 4-pt scale and are an open question for engineering.
