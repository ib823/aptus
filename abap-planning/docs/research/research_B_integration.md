# Research B: Integration and portability of an ABAP Cloud budgeting/planning app across SAP customers

Research date: 2026-10-20. Sources are authoritative only: help.sap.com, github.com/SAP, support.sap.com, the PDP Commissioner (pdp.gov.my), JDN/MyGovCloud (jdn.gov.my), and learn.microsoft.com for Q7 only.

## How the sources were accessed (read this first)

- **help.sap.com.** Read through the portal's own JSON endpoints (`/http.svc/deliverableMetadata`, `/http.svc/pagecontent`, `/http.svc/elasticsearch`). Each page was read at the "Latest" version the portal served on the research date:
  - SAP S/4HANA Cloud Public Edition **2608 (2608.500)**
  - SAP S/4HANA **2025 FPS02 (Oct 2026)**
  - SAP Analytics Cloud **Q3 2026 (2026.15)**
  - ABAP platform **2025 FPS02**
  - SAP BTP "Cloud" (continuously updated)
- **api.sap.com (SAP Business Accelerator Hub).** Could not be read. Every page and the catalog OData redirect to an OAuth login (`sappubliccatalog.authentication.eu10…`). API states shown only on the Hub, such as "deprecated" badges or successor links, are therefore **not confirmed**. The help.sap.com API lists for the same release were used instead.
- **community.sap.com.** Returned HTTP 403 (a Cloudflare challenge) to both WebFetch and curl. Blog content could not be read directly. Where a claim depends on a blog, this is flagged.
- **SAP Cloudification Repository.** Cloned from github.com/SAP/abap-atc-cr-cv-s4hc at commit `cd34bed`, dated **16 Oct 2026**. All counts and release states below come from its JSON files.
- **Naming changes seen in current SAP documentation:**
  - help.sap.com now uses the name **"SAP Business AI Platform, ABAP environment"** (docs product `ABAP_ENVIRONMENT`) for what was "SAP BTP, ABAP environment". The BTP doc set still carries the title "SAP Business Technology Platform (SAP BTP)".
  - The Cloudification Repository README calls S/4HANA Cloud Public Edition "SAP Cloud ERP" and Private Edition "SAP Cloud ERP Private".
  - This report uses the familiar names.

Confidence scale:
- **High:** read verbatim on the authoritative page.
- **Medium:** inferred from several authoritative pages, or the authoritative page is a draft or an older release.
- **Low:** secondary or indirect.

## Conflicts and flags

1. **`API_JOURNALENTRYITEMBASIC_SRV`.** It is not deprecated in help 2608, but help restricts it to SAC integration only. A report suggesting it as the general actuals feed conflicts with SAP's restriction. Use `API_GLACCOUNTLINEITEM_SRV`, or released CDS in-stack.
2. **"Deletion" vs "reversal" of plan data.** SAP Help says values in scope are "set to zero" / "reversed" before posting. The blog's wording ("deleted") is looser, but the functional effect (replace within scope) is the same.
3. **PCE released-object lists vs `CL_RFC_DESTINATION_PROVIDER`.** The class is released for Public Edition, BTP and PCE 2022, but absent from the PCE 2023 and 2025 JSON files. PCE 2025 adds `IF_APPDESTINATION*` (communication targets). The current help recommends communication targets for one code line. Do not assume the comm-arrangement RFC pattern is identical on PCE 2023+.
4. **Budget transfer APIs.** The apps exist (F4307 for cost centres, F4173A for PSM), but no released create/transfer API was found in Public Edition. PSM `API_BDGTDOCBDGTMGMT` is read-only.
5. **PSM AVC and BAC are mutually exclusive** in Public Edition.
