KNOWN TRAP — do not port the preview's CSS collision
The previews contain a class-name collision: `.otp` is used for BOTH
the OTP input box AND the OTP event-chip modifier, which renders the
event chip malformed on routes 3.3 and 3.5. Brief §6.7 explains it.
In the real repo, namespace them: the input is `<OtpInput>` with a
scoped class (never bare `otp`); the event chip's OTP variant is
`event-chip--otp` or a `variant="otp"` prop. Do not reproduce the bug.

SCOPE GUARDRAILS (brief §9 — out of scope for this pass)

logic. No localization wiring, no dark mode activation, no Vercel
hostname rename. Visual restoration only. Behavior must not change —
the Batch A and Batch B fixes already verified on production
(inline form errors, Extend/Revoke/Reissue, audit events) must keep
working exactly as they do now.

DONE = the brief's §8 acceptance checklist passes
